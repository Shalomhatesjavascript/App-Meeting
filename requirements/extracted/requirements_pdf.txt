2. Sequence Diagram – Authentication Flow
User -> Frontend: Enter credentials
Frontend -> Backend: POST /auth/login
Backend -> Database: Validate user
Database -> Backend: User data
Backend -> Frontend: JWT Token
Frontend -> User: Login successful

This diagram explains how authentication requests flow through the system.

3. Sequence Diagram – Matching & Messaging
User -> Frontend: Swipe Right
Frontend -> Backend: POST /match/like
Backend -> Database: Store Like
Backend -> Backend: Check mutual interest
Backend -> Database: Create Match
Backend -> Frontend: Match confirmed
Frontend -> User: Open Chat
User -> Frontend: Send Message
Frontend -> Backend: POST /messages
Backend -> Database: Save Message

This sequence diagram shows how users are matched and allowed to chat.

8. Page Interaction & Navigation Explanation
Login/Register Page: - Communicates with Auth API - Redirects to Profile Setup upon success
Profile Page: - Sends profile data to Backend - Required before accessing Discover page Discover
Page: - Fetches user cards - Sends swipe actions to Matching API Matches Page: - Displays
mutual matches - Entry point to Chat page Chat Page: - Sends and receives messages - Enforces
subscription limits Subscription Page: - Handles payments - Updates user access level Admin
Dashboard: - Restricted to admins - Manages users, reports, and analytics
